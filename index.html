Efecto Rollover

Pasa el ratón sobre el botón para ver el cambio

¿Cómo funciona?

Este botón usa Alpine.js para detectar eventos @mouseenter y @mouseleave. La propiedad hover cambia dinámicamente, modificando clases CSS, texto, color de fondo, sombras e incluso un pequeño icono. ✔ Sin redirecciones, solo efecto visual "rollover".

🖱️ Efecto Rollover puro | Sin enlaces | Tecnología: Alpine.js + Tailwind CSS
